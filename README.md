# Personal Portfolio — Poshan Gaire

A clean, fast, and minimalist single-page developer portfolio built with HTML5 and Tailwind CSS.

🌐 **Live Website:** [poshangaire.com.np](https://poshangaire.com.np)

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS
- **Hosting:** Netlify
- **Domain:** Custom `.com.np` 
- **Version Control:** Git & GitHub

## 🚀 Features
- ⚡ Ultra-lightweight and fast loading time
- 📱 Fully responsive layout
- 🎯 Minimalist, high-contrast accessible design
- 📄 Single-file setup (`index.html`)
